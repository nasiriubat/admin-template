# Theme and Branding System

## Goal

Allow meaningful client customization without allowing themes to destroy usability or component consistency.

## Editable branding

- product name
- logo
- dark logo
- compact logo
- favicon
- application icon
- login visual
- email logo

## Editable color tokens

- primary
- secondary
- accent
- canvas
- surface
- text
- muted text
- border
- success
- warning
- danger
- info

The system should generate compatible shades rather than requiring users to define every shade manually.

## Editable typography

Choose from approved font families.

Allow separate heading font only if the implementation remains visually controlled.

## Editable shape

- card radius
- button radius
- input radius

## Editable effects

- shadow strength
- border prominence
- glass intensity

## Motion setting

- Minimal
- Standard
- Expressive

## Density setting

- Compact
- Comfortable
- Spacious

## Theme presets

Ship at least:

- Professional
- Modern SaaS
- AI Futuristic
- Data Dense

Optional marketing preset:

- Apple Inspired

## Theme export

V2 should support JSON export and import.
