# Accessibility

## Requirements

- semantic HTML
- keyboard navigation
- visible focus states
- accessible labels
- ARIA only where necessary
- color contrast
- status not communicated by color alone
- touch targets appropriate for mobile
- screen reader friendly dialogs and menus
- reduced motion support
- text alternatives for meaningful visualizations

## Charts

Charts should expose a textual summary or data table when practical.

## Forms

Errors must be associated with their fields and announced when appropriate.

## Modals and drawers

- trap focus
- restore focus on close
- support Escape where appropriate
- announce title and purpose
